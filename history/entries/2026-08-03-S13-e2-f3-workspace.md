## Objective

Implement the workspace module (`src/core/workspace/`) with four use cases: `createReviewWorktree`, `cleanupWorktree`, `listOrphanWorktrees` (story #17), and `computeReviewDiff` (story #18). This completes E2.F3 and the entire E2 epic.

## Decisions

| ID | Decision | Alternatives considered | Why | Authorship |
|----|----------|-------------------------|-----|------------|
| S13-D1 | Single PR for both E2.F3 stories | Separate PRs per story | Same feature module, tightly coupled (shared fake, shared barrel). Workflow convention allows sharing PRs for related stories in the same feature. | `claude` |
| S13-D2 | `CleanupPolicy` as string union type in own file | Enum, or inline in cleanup-worktree | String union is simpler, aligns with TypeScript idioms, separate file keeps it importable without pulling the use case. | `claude` |
| S13-D3 | Optional `now?: () => number` in `CreateReviewWorktreeDeps` for test timestamp injection | Fixed timestamps, vitest fake timers | Explicit DI is simpler and more deterministic than mocking `Date.now()`. | `claude` |
| S13-D4 | `wt.path.startsWith(\`\${deps.worktreesDir}/\`)` with trailing slash | `startsWith(deps.worktreesDir)` without slash | Prevents false match on sibling directories (e.g. `/sentinel/worktrees-backup`). Found by 4R code review. | `claude` |
| S13-D5 | Token estimation as `Math.ceil(text.length / 4)` — no external tokenizer | Import a tokenizer library | Core module cannot import I/O libraries (architecture guard). Heuristic is sufficient for size-bounding; limit is a tunable threshold. | `claude` |
| S13-D6 | Greedy largest-first truncation, tie-break by last-in-diff-order (`>=`) | Round-robin, proportional reduction | Greedy removes fewest files to fit within limits. Tie-break by highest index is deterministic and predictable. | `claude` |
