## Deviations

- **D5 against recommendation**: the user chose structural-only verification. The review and result steps, exit codes 0/1 and the interactive flow rest on code and fixtures, not a real engine run.
- **4R rubric overridden** (S31-D11): the docs-only diff is `trivial` by the rubric, but full-4r ran on the user's brief. Result: 0 severe, 12 info rows, all addressed in S6.
- **Incident, review worker changed git state** (d-019): during the 4R fan-out a read-only lens worker ran `git checkout 8fb52de` (reflog 2026-10-03 19:24:36Z), detaching HEAD. Seven later commits, including S6, landed on the detached HEAD. Every `git push origin <branch>` pushed the stale ref, and `-q` hid that. Final QA caught it (W3). Recovery: ancestor check, fast-forward of the branch to `8e91c5a`, normal push; no history rewritten. Lesson: review envelopes must forbid checkout, and the orchestrator checks `git status -sb` after a fan-out and after each push.
- **Plan amendment** after the review: S6 was added outside the protocol fix-round budget, because info rows never enter the protocol loop.
- **Bootstrap staleness accepted as non-material** at preflight: config and catalog still said E7.F1.H1 was uncommitted. Not refreshed this session.
